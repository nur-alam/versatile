Use short and clear commit messages.
Start with conventional commit prefixes like "feat:", "fix:", "chore:", or "refactor:" etc.
Keep the message specific to the change and concise.
if changes are little, you can use the prefix "chore:".
if changes are very few, you don't need to prefix at all.
if changes are many, you can use the prefix "feat:".
if changes are major, you can use the prefix "fix:".
if changes are minor, you can use the prefix "refactor:".

don't add this kind of text actually 'fix trailing newline in the SCSS file', if this is not the only change in the commit.
